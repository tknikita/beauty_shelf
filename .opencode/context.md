# Project Context

## Environment
- Language: Python 3.12
- Frontend: Flet 0.84 (Pyodide/WASM in browser)
- Backend: FastAPI + SQLite
- Build: `flet build web . --output ../frontend_build`
- Test: `pytest ../tests/ -v`

## Project Type
- Application (Web frontend + REST backend)
- Docker-based deployment: nginx:alpine + python:3.12-slim

## Infrastructure
- Container: Docker Compose (backend + frontend)
- Nginx serves static files + proxies /api/* → backend:8000
- CI/CD: Manual deploy.sh

## Structure
- Source: frontend/ (Flet), backend/ (FastAPI)
- Tests: tests/
- Build output: frontend_build/ (generated by `flet build web`)
- Entry: frontend/main.py, backend/main.py

## Conventions
- Naming: snake_case for Python
- API: RESTful, /api/* prefix
- Database: SQLite with simple row queries

## Current Issue
- Pyodide micropip fails to fetch packages from PyPI: `pyodide.http.AbortError: Failed to fetch`
- Google Fonts also fails: `ERR_SOCKET_NOT_CONNECTED`
- Possible causes: proxy/CORS issue, stale build, missing frontend_build
