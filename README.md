# 💄 Beauty Shelf

Трекер запасов уходовой и декоративной косметики с отслеживанием сроков годности.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Flet](https://img.shields.io/badge/Flet-0.26+-purple)
![SQLite](https://img.shields.io/badge/Database-SQLite-green)

## Возможности

- ✨ Минималистичный и уютный интерфейс в стиле beauty-брендов
- 📅 Отслеживание сроков годности с визуальными индикаторами
- 🔔 Push-уведомления о истекающих продуктах
- 📂 Категории продуктов (уходовая и декоративная косметика)
- 🔍 Поиск по названию и назначению
- 🧴 Фильтрация по типу (уходовая / декоративная)
- 📱 Кроссплатформенность: Windows, macOS, Linux, Web, iOS, Android

## Установка

```bash
cd beauty_shelf

# Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate  # Windows

# Установите зависимости
pip install -r requirements.txt
```

## Запуск

```bash
source venv/bin/activate
python main.py
```

Приложение запустится с графическим интерфейсом. Поддерживает:
- **Desktop**: Windows, macOS, Linux (создаёт нативное окно)
- **Web**: Браузерная версия
- **Mobile**: iOS/Android (через Flet)

## Поля продукта

| Поле | Тип | Описание |
|------|-----|---------|
| Название | str | Название продукта |
| Тип | enum | `care` (уходовая) / `decorative` (декоративная) |
| Категория | str | Подкатегория продукта |
| Назначение | str | Для чего используется |
| Срок годности | date | Дата окончания срока годности |

## Уведомления

Приложение проверяет продукты с истекающим сроком годности:
- При запуске показывает in-app уведомление
- Настраиваемый порог: 3/5/7/14/30 дней до истечения
- Системные уведомления (Desktop: macOS notify-send, Windows toast, Linux)
- Включить/выключить в настройках

## Скриншоты

Интерфейс включает:
- Карточки продуктов с индикаторами срока годности
- Цветовую кодировку: зелёный (норма), жёлтый (скоро), красный (просрочено)
- Иконки категорий на каждой карточке
- Фильтры по типу косметики
- Поиск по названию и назначению
- Модальные окна для добавления и редактирования
- Страницу настроек для уведомлений

## Технологии

- **Flet** — фреймворк для кроссплатформенных приложений (Flutter-based)
- **SQLite** — встроенная база данных
- **Python 3.10+** — язык программирования
- **plyer** — системные уведомления
